# Customer Journey Analytics에서 연결에 새 데이터 추가

Customer Journey Analytics 연결에 다른 채널의 새 데이터를 추가하여 분석에서 더 많은 가치를 얻을 수 있습니다. 또한 이 새 데이터를 병합하기 위한 요구 사항과 구성 설정을 사용해 해결할 수 있는 분석 및 보고서에 대한 영향을 이해합니다.

교차 채널 분석에 대한 자세한 내용은 [설명서](https://experienceleague.adobe.com/docs/analytics-platform/using/cca/overview.html?lang=ko-KR){target="_blank"}를 참조하십시오.
