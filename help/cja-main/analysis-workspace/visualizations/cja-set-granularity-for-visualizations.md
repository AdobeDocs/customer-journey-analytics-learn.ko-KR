트렌드 시각화 설정의 세부 기간 선택기를 사용하여 데이터가 표시되는 방식을 쉽게 조정할 수 있습니다. 이 기능을 사용하면 요구 사항에 맞게 시각화를 세분화하여 데이터 분석을 간소화합니다. 워크플로우를 최적화하고 데이터 통찰력을 보다 쉽게 이용할 수 있도록 하는 방법을 살펴봅니다.
