# 하위 이벤트를 사용한 개체 수준 세분화

보다 정밀한 세분화 및 보고를 위해 [!DNL Customer Journey Analytics]에서 [!UICONTROL 하위 이벤트 분석]을 사용하는 방법에 대해 알아봅니다. 개체 수준 세그멘테이션은 Adobe Experience Platform의 확장 가능한 데이터 모델을 사용하여 과도한 속성을 제거하고, 매출 분석을 개선하며, 복잡한 데이터 세트 간에 더 깊이 있는 탐색을 가능하게 합니다.

추가 정보는 [설명서](https://experienceleague.adobe.com/en/docs/analytics-platform/using/cja-components/segments/sub-event){target="_blank"}를 참조하십시오.
